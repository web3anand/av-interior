# AV Interior — invoices and quotations

Print-ready bills for AV Interior Decoration. Edit the letterhead, buyer, and lines, then print or save as PDF. Invoices and quotations stay in this browser (`localStorage`). Hosting the site does not store bills on a server.

```bash
npm install
npm run dev
```

Open http://127.0.0.1:8080

## Deploy

The production build uses the Vercel preset (`npm run build`). Import this repo in Vercel and leave the build command as `npm run build`. No database is required.
